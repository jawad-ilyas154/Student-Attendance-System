# Student Attendance System

## About the Project
The Student Attendance System is an Android mobile application developed to make student attendance management easier and more organized. It provides a digital way to manage student records and maintain daily attendance.

This project is developed using Java and XML in Android Studio. It aims to reduce manual paperwork, save time, and make attendance management more convenient.

## Technologies Used
- **Java** – Application programming.
- **XML** – User interface design.
- **Android Studio** – Development environment.

## Main Features
- Student registration.
- Manage student records.
- Mark students as Present or Absent.
- View attendance records.
- Maintain daily attendance history.
- Simple and user-friendly interface.

## Project Structure
The project is organized into Java source files and XML layout files. Java handles the application functionality, while XML is used to design the application screens.

## Development Environment
- Android Studio
- Java Development Kit (JDK)
- Android SDK

## Installation and Setup

1. Download or clone this repository.
2. Open Android Studio.
3. Select **Open Project** and choose the downloaded project folder.
4. Allow Gradle to sync and complete the project setup.
5. Connect an Android device or start an emulator.
6. Click the Run button to launch the application.

## Project Purpose
The purpose of this project is to demonstrate the development of an Android-based attendance management application using Java and XML. It provides practical experience in Android application development and user interface design.
